## Порядок компиляции

1. Откройте этот проект в Android Studio
2. Дождитесь завершения синхронизации Gradle
3. Нажмите «Build» > «Build Bundle(s) / APK(s)» > «Build APK(s)»
4. Сгенерированный APK находится в каталоге `app/build/outputs/apk/`

## Примечания

- Требуется Android Studio Hedgehog или более поздней версии
- Требуется JDK 17 или более поздней версии
- При первой компиляции необходимо загрузить зависимости, поэтому убедитесь, что интернет-соединение работает
